# Holdfast Panel

Windows-приложение для управления серверами, на которых стоит
[holdfast](https://github.com/viktorplus/holdfast). Приложение подключается к
серверам по SSH и вызывает на них `holdfast`; агента на сервере нет.

Состояние: этап 1 из плана (список серверов, подключение нового сервера).
Монитор, бэкапы и шаблоны — следующие этапы.

## Запуск

```sh
python -m venv .venv
.venv\Scripts\pip install -e .[dev]
.venv\Scripts\python -m holdfast_panel
```

## Что умеет сейчас

- хранит список серверов (`%APPDATA%\HoldfastPanel\servers.json`: имя, адрес,
  порт, логин, отпечаток ключа сервера; паролей там нет);
- «Добавить сервер»: показывает отпечаток ключа сервера для сверки, затем по
  паролю один раз кладёт ключ панели в `~/.ssh/authorized_keys` и проверяет вход
  по ключу. Пароль нигде не сохраняется;
- показывает, в сети ли сервер и какая версия holdfast на нём стоит.

Ключ панели (`%APPDATA%\HoldfastPanel\id_ed25519`) зашифрован; его пароль лежит
в диспетчере учётных данных Windows. Если ключ изменился на сервере (отпечаток
не совпал с принятым раньше), подключение блокируется.

## Проверка

```sh
.venv\Scripts\python -m pytest
.venv\Scripts\python -m ruff check .
```

Тесты поднимают настоящий SSH-сервер в процессе теста. Командам он выполняет в
Git Bash с временным `HOME`, поэтому на Windows нужен Git for Windows
(`C:\Program Files\Git`) или переменная `GIT_BASH` с путём к `bash.exe`; иначе
эти тесты пропускаются.
